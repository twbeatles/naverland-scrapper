# Naver Real Estate Scraper & Price Tracker

[![Python Version](https://img.shields.io/badge/Python-3.11+-3776AB?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)
[![UI Framework](https://img.shields.io/badge/UI-PyQt6%20Fluent%20Widgets-0078D4?style=flat-square)](https://github.com/zhiyiYo/PyQt-Fluent-Widgets)
[![Crawl Engine](https://img.shields.io/badge/Engine-Playwright%20Fast--Path-2EAD33?style=flat-square&logo=playwright&logoColor=white)](https://playwright.dev/)
[![Version](https://img.shields.io/badge/Version-v15.4-orange?style=flat-square)](#)

**네이버 부동산 아파트·빌라 매물 수집, 가격 변동 추적, 예약 수집 및 Excel/CSV 내보내기를 지원하는 Windows 데스크톱 도구입니다.**

Naver Real Estate Scraper로 매물을 수집하는 데서 그치지 않고, 로컬 SQLite에 가격 이력을 쌓아 price tracker, listing monitor, local analytics 도구로 활용할 수 있습니다. Windows 11 Fluent Design GUI에서 단지 URL/ID 또는 지도 좌표로 수집 대상을 지정합니다.

## 핵심 기능

- **매물 수집과 지도 탐색**: 아파트(APT)·빌라/연립(VL)의 단지 ID·URL 수집과 좌표 기반 광역 탐색을 지원합니다.
- **가격 이력과 매물 모니터링**: 일별 가격 스냅샷, 신규·가격 변동·사라진 매물을 확인합니다.
- **예약 자동 수집**: 단지 묶음 또는 지도 영역을 지정한 시간에 수집할 수 있습니다.
- **로컬 분석**: 대시보드와 가격 통계로 수집 데이터를 살펴보고, 모든 데이터는 로컬 SQLite에 보관합니다.
- **내보내기**: 필요한 열을 선택해 Excel 또는 CSV로 저장합니다.

## 빠른 시작

Python 3.11 이상에서 아래 명령으로 설치하고 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
playwright install chromium
python app_entry.py
```

## 사용 전 안내

이 프로젝트는 네이버의 공식 API 제품이 아닙니다. 대상 사이트의 변경으로 일부 기능이 동작하지 않을 수 있으며, 과도한 요청을 권장하지 않습니다. 사용자는 네이버 서비스 약관 및 관련 법규를 준수해야 합니다.

## ✨ 주요 기능

- ⚡ **초고속 비동기 수집 엔진**: Playwright 기반 Article API 다중 페이지 Fast-Path 수집 및 모바일/웹 응답 캡처 지원 (Selenium 자동 fallback 내장)
- 🏢 **자산 유형 지원**: 아파트(APT) 및 빌라·연립(VL) 매물 수집 지원 (분양권 포함 옵션 지원)
- 🗺️ **2가지 수집 모드**: 단지 ID/URL 직접 지정 수집(`매물 수집`) + 지도 위도/경도 반경 탐색 수집(`지도로 찾기`)
- 🔍 **풍부한 상세 정보 보강**: 중개업소명, 중개사 연락처, 기전세가, 갭투자 금액/비율, 확인일자, 동/층/향 정보
- 📊 **3가지 결과 뷰**: 표준 테이블 뷰 / 동일 매물 묶기(컴팩트) 뷰 / 시각적 카드 뷰
- 📈 **시세 분석 & 가격 이력 추적**: 매 수집 시 일별 가격 스냅샷 자동 기록, 신규 등록 매물 / 가격 상승·하락 / 사라진(거래완료/삭제) 매물 추적
- ⏰ **예약 자동 수집**: 원하는 시간(예: 매일 오전 09:00)에 지정한 단지 그룹 또는 좌표 영역을 백그라운드 자동 수집
- 📑 **엑셀/CSV 맞춤 내보내기**: 원하는 컬럼만 선택하고 순서를 지정할 수 있는 엑셀 템플릿 내보내기

### 1. 매물 수집 (단지 기반 수집)

단지 번호나 웹 URL을 직접 입력하여 특정 단지들의 매물을 집중적으로 수집하는 화면입니다.

#### ① 단지 추가하기
- **단지 찾기 (기본 방법)**: `단지 찾기`를 눌러 단지 이름이나 지역 이름(예: `래미안`, `반포자이`, `반포동`)으로 검색하고, 원하는 단지를 체크해 추가합니다. 지역 탭에서 지역을 고르면 **지도로 찾기**의 탐색 위치로 보낼 수 있습니다.
- **불러오기 메뉴**:
  - `내 단지에서 고르기`: 저장해 둔 단지에서 선택
  - `단지 묶음 불러오기`: 묶음에 든 단지를 한 번에 추가
  - `최근 수집 조건 불러오기`: 이전에 수집한 단지·거래 종류·조건을 그대로 복원
  - `네이버 부동산 주소 붙여넣기`: 단지·매물 페이지 주소(또는 단지 번호)를 한 줄에 하나씩 붙여 넣고 `단지 확인하기` → `체크한 단지 추가`
  - 지원 주소 형식:
    - `https://new.land.naver.com/complexes/102378`
    - `https://land.naver.com/complex?complexNo=123456`
    - `https://fin.land.naver.com/articles/2539123450` (매물 주소에서 단지를 찾아 줌)
    - `https://m.land.naver.com/article/info/2513105556`
- **단지 번호로 직접 추가**: 접혀 있는 `단지 번호로 직접 추가`를 펼쳐 번호(예: `3833`)와 주택 종류(아파트/빌라)를 넣고 추가합니다.
- 목록 아래의 `내 단지에 저장`으로 목록을 저장해 두면 다음부터 불러오기로 바로 가져옵니다.

#### ② 거래 종류와 조건
- **거래 종류**: `매매`, `전세`, `월세` 중 수집할 종류를 체크합니다.
- **조건·속도 설정 (선택, 기본 접힘)**: 범위를 좁힐 때만 펼칩니다.
  - `면적 범위 지정`: 최소~최대 면적(㎡)
  - `가격 범위 지정`: 매매 / 전세 / 월세 보증금 / 월세를 만원 단위로 지정 (10,000만원 = 1억)
  - `수집 속도`: 기본값 `보통` 권장. 너무 빠르면 네이버에서 잠시 접속을 막을 수 있습니다.

#### ③ 수집 실행
화면 왼쪽 아래에 항상 보이는 실행 바에서 조작합니다.
- **수집 시작 (`Ctrl+R`)**: 수집을 시작하면 아래쪽 진행 표시에 현재 단지와 남은 시간이 나타납니다.
- **중지 (`Ctrl+Shift+R`)**: 진행 중인 수집을 멈춥니다. 그때까지 모은 결과는 남습니다.
- **결과 저장 (`Ctrl+S`)**: 엑셀·CSV·JSON으로 저장합니다.

#### ④ 결과 보기
- **표로 보기 / 카드로 보기**: 툴바 버튼으로 전환합니다. 카드에서는 별(☆)을 눌러 즐겨찾기에 담을 수 있습니다.
- **정렬·필터 메뉴**:
  - `정렬`: 가격 낮은/높은 순, 면적 좁은/넓은 순, 단지 이름순, 거래 종류순
  - `상세 필터`: 가격·면적·층(저/중/고층), 새로 나온 매물·가격이 내린 매물·가격이 바뀐 매물만 보기, 포함/제외 단어
  - `같은 매물 묶어 보기`: 여러 중개소가 올린 같은 매물을 한 줄로 묶음
  - `표에 보일 항목`: 확인일, 동, 타입명, 중개소, 전화 등 추가 항목 표시
- **결과에서 찾기 (`Ctrl+F`)**: 단지 이름, 가격, 층, 특징 단어로 즉시 좁혀 봅니다.
- **진행 기록 탭**: 수집 과정을 쉬운 말로 보여 줍니다. 문제가 생겼을 때는 `자세히 보기`를 켜면 진단용 세부 기록까지 볼 수 있습니다.
- 결과가 없을 때는 빈 표 대신 상황에 맞는 안내(아직 수집 전 / 수집 중 / 조건에 맞는 매물 없음)가 표시됩니다.

#### ⑤ 저장과 내보내기
- `결과 저장` 메뉴에서 **지금 보이는 목록**(묶기·필터 적용) 또는 **수집한 전체 원본** 중 골라 저장합니다.
- `엑셀에 담을 항목 고르기`: 담을 항목을 체크하고 끌어서 순서를 바꿉니다.
- 결과 항목을 **두 번 누르면** 네이버 부동산 매물 페이지가 열립니다.

### 2. 지도로 찾기 (좌표 기반 광역 탐색)

단지 이름을 몰라도 지역만 고르면 그 주변의 아파트와 빌라·연립 단지를 자동으로 찾아 수집합니다.

1. **지역 찾기**: 동·구 이름(예: `반포동`, `분당구`)을 검색해 탐색할 위치를 고릅니다. 위도·경도를 직접 넣을 필요가 없습니다.
2. **주변까지 넓히기**: `0단계`는 정한 위치의 지도 한 화면만, `1~6단계`는 주변을 점점 넓게 훑습니다 (넓을수록 시간이 더 걸립니다).
3. **주택 종류**: `아파트`, `빌라·연립` 체크
4. **좌표 직접 입력·세부 설정 (기본 접힘)**: 위도/경도, 지도 확대 단계(12~18), 지도 이동 간격, 옮길 때마다 대기 시간. 보통은 기본값 그대로 씁니다.
5. **탐색 시작**을 누르면 찾은 단지가 왼쪽 `찾은 단지` 표에 쌓이고 매물 수집이 이어집니다.

### 3. 보관함 관리 (내 단지 / 단지 묶음 / 즐겨찾기)

수집한 단지와 매물을 체계적으로 분류하고 관리할 수 있습니다.

- **내 단지**:
  - 저장해 둔 단지 목록입니다. 이름·번호·메모로 찾을 수 있습니다.
  - `메모 고치기`, `삭제`(여러 줄을 한꺼번에 골라 삭제 가능)를 제공합니다. 삭제할 때 가격 기록까지 지울지 선택합니다.
- **단지 묶음**:
  - 여러 단지를 주제별(예: `송파구 30평대`, `관심 단지`)로 묶습니다. `새 묶음` → `단지 넣기` 순서입니다.
  - 묶음은 **매물 수집의 불러오기**와 **예약 수집**에서 바로 씁니다. 묶음을 지워도 단지는 `내 단지`에 남습니다.
- **즐겨찾기**:
  - 결과를 `카드로 보기`로 바꾼 뒤 카드의 별(☆)을 눌러 담은 매물 모음입니다.
  - `메모 고치기`, `네이버 부동산에서 보기`, `즐겨찾기에서 빼기`를 지원합니다.

### 4. 분석 및 모니터링 (대시보드 / 가격 통계 / 수집 기록)

수집된 데이터를 시각화하고 가격 변동을 추적합니다.

- **대시보드**:
  - 현재 수집 매물의 전체 요약 (총 매물 수, 평균가, 평당가 등)
  - 매매/전세/월세 가격 분포 및 평형별 시세 통계
  - 신규 등록 매물 / 가격 상승·하락 매물 / 사라진 매물(거래완료 또는 매물 회수) 분석 차트 제공
- **가격 통계 (시세 추이)**:
  - 단지별, 거래 유형별, 평형별 일별 가격 스냅샷 이력을 선 그래프로 시각화
  - 일자별 최저가 / 최고가 / 평균가 변동 추이 테이블 확인 (월세의 경우 보증금/월세 기준 전환 가능)
- **수집 기록**:
  - 과거 수집 일시, 단지명, 수집 매물 수, 신규/변동 매물 건수 기록 조회 및 관리

### 5. 자동화 (예약 수집 & 트레이 백그라운드)

매일 특정 시간에 PC가 켜져 있으면 자동으로 수집을 수행하도록 스케줄을 구성할 수 있습니다.

1. **수집 방법 선택**:
   - `단지 묶음 수집`: 고른 **단지 묶음**의 단지를 차례로 수집
   - `지도 범위 수집`: 정한 위치 주변을 지도로 훑어 수집. `「지도로 찾기」에서 정한 위치 가져오기`를 누르면 그 화면에서 고른 지역과 범위를 그대로 가져옵니다.
2. **시작 시간**: 수집을 시작할 시각(예: `09:00`) 지정
3. **매일 자동으로 수집하기** 체크
4. **트레이 최소화 활용**: 설정에서 `창을 닫을 때 트레이로 최소화`를 켜두면, 창을 닫아도 백그라운드(시스템 트레이)에서 동작하며 정해진 시간에 자동 수집을 수행합니다.

### 6. 환경 설정 가이드

상단 메뉴 `파일` → `설정` 또는 단축키 `Ctrl+,`를 통해 설정 창을 엽니다. 설정은 **기본**과 **고급**으로 나뉩니다.

#### 기본 설정 (일상 사용)
| 설정 항목 | 권장값 | 설명 |
|---|---|---|
| **테마** | 어두운 테마 / 밝은 테마 / 윈도우 설정 따르기 | Fluent UI 다크/라이트 모드 전환 (시스템 연동 시 OS 설정 추적) |
| **수집 속도** | 보통 | 크롤링 속도 프리셋 (너무 빠르면 차단 위험 증가) |
| **분양권 매물 포함** | 끔 (필요 시 켬) | 분양권(PRE) 매물을 포함하여 수집할지 여부 |
| **상세 정보 가져오기** | 켬 | 중개업소 연락처, 기전세가, 갭금액 등 상세 조회 (끄면 수집 속도 극대화) |
| **같은 매물 묶어 보기** | 켬 | 동일 매물 중복 표기를 줄이고 묶어서 표시 |
| **새 매물 / 가격 변동 표시**| 켬 | 신규 매물 및 이전 대비 가격 변동 태그 표시 |

#### 고급 설정 (성능 & 수집 엔진 튜닝)
| 설정 항목 | 기본값 | 설명 |
|---|---|---|
| **수집 엔진** | Playwright (권장) | 기본 고속 엔진 (Selenium은 보조/fallback) |
| **자동 재시도** | 켬 (3회) | 네트워크 오류나 일시적 차단 발생 시 자동 재시도 |
| **상세 정보 보완 조회** | 켬 | 모바일 프론트 API를 통해 누락된 중개/상세 데이터 보충 |
| **상세 HTML 건너뛰고 API만** | 끔 (장애 시 켬) | 네이버 상세 페이지 404/429 오류 발생 시 API로만 경량 조회 |
| **단지마다 상세 조회 한도** | 제한 없음 (0) | 대단지 수집 시 부하를 줄이기 위한 단지당 상세 조회 최대 건수 |
| **목록 페이지 사이 대기** | 150ms | 목록 요청 간 딜레이 (429 Rate Limit 방지) |
| **상세 정보 동시 조회 수** | 4 | 상세 페이지 동시 조회 수 (시작 시 최대 2개만 생성, 수요에 따라 상한까지 확장) |
| **무거운 리소스 차단** | 켬 | 이미지, 웹폰트 로딩을 차단하여 네트워크 트래픽 및 메모리 절감 |
| **백그라운드 수집(헤드리스)** | 켬 | 브라우저 창을 띄우지 않고 백그라운드에서 조용히 수집 |

## 💡 실전 활용 팁

1. **단지 ID를 찾는 가장 쉬운 방법**:
   - PC 웹 브라우저에서 네이버 부동산 접속 ➔ 원하는 아파트 단지 클릭
   - 브라우저 주소창 URL 확인: `https://new.land.naver.com/complexes/102378` ➔ 끝의 숫자 `102378`이 단지 ID입니다.
   - 단지 번호를 찾기 귀찮다면 URL 전체를 복사해서 프로그램의 **[URL]** 일괄 등록 창에 그냥 붙여넣으세요!
2. **안정적인 대량 수집 요령**:
   - 수십 개 이상의 대형 단지를 한 번에 수집할 때는 `수집 속도`를 `보통` 또는 `안전`으로 설정하세요.
   - 설정 → 고급에서 `목록 페이지 사이 대기(ms)`를 `200~300ms` 정도로 늘려주면 429(Too Many Requests) 차단을 효과적으로 예방할 수 있습니다.
3. **갭투자 및 급매물 모니터링**:
   - 관심 단지들을 `단지 묶음`으로 등록해 두고 매일 아침 `예약 수집`을 실행합니다.
   - 수집 후 `고급 필터`에서 `🆕 신규 매물만` 또는 `📉 가격 하락만`을 체크하면 밤사이 새로 나온 매물이나 호가를 낮춘 급매물을 즉시 포착할 수 있습니다.
   - 결과 표의 `갭금액` 및 `갭비율(%)` 컬럼을 확인하여 전세가율이 높은 매물을 손쉽게 선별할 수 있습니다.

## 📦 단독 실행 파일 빌드 (PyInstaller)

Python이 설치되지 않은 환경에서도 배포 및 실행이 가능한 단독 패키지를 빌드할 수 있습니다 (`naverland-scrapper.spec` 사용).

```powershell
# 기본 onedir 빌드 (dist/naverland/ 생성)
python -m PyInstaller --clean --noconfirm naverland-scrapper.spec
```

#### 빌드 커스터마이징 환경 변수
| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `NAVERLAND_ONEFILE=1` | 0 | 단일 실행 파일(`.exe`)로 패키징 |
| `NAVERLAND_BUNDLE_CHROMIUM=0` | 1 | 빌드에서 Chromium 번들을 제외하여 배포 용량 대폭 절감 |
| `NAVERLAND_INCLUDE_SELENIUM=0` | 1 | Selenium 의존성을 제외하고 Playwright 전용 경량 빌드 생성 |
| `NAVERLAND_CONSOLE=1` | 0 | 디버깅용 콘솔 창을 실행 시 함께 표시 |

*경량 슬림 빌드 예시:*
```powershell
$env:NAVERLAND_BUNDLE_CHROMIUM="0"
$env:NAVERLAND_INCLUDE_SELENIUM="0"
python -m PyInstaller --clean --noconfirm naverland-scrapper.spec
```
