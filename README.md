# Naverland Scrapper Pro Plus

[![Python Version](https://img.shields.io/badge/Python-3.11+-3776AB?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)
[![UI Framework](https://img.shields.io/badge/UI-PyQt6%20Fluent%20Widgets-0078D4?style=flat-square)](https://github.com/zhiyiYo/PyQt-Fluent-Widgets)
[![Crawl Engine](https://img.shields.io/badge/Engine-Playwright%20Fast--Path-2EAD33?style=flat-square&logo=playwright&logoColor=white)](https://playwright.dev/)
[![Version](https://img.shields.io/badge/Version-v15.0-orange?style=flat-square)](#)

**네이버 부동산(Npay / `new.land` / `fin.land`)의 실시간 매물 정보를 초고속으로 수집하고, 가격 변동 및 시세 이력을 추적·분석할 수 있는 데스크톱 애플리케이션입니다.**

현대적인 Windows 11 Fluent Design UI가 적용되어 직관적이며, 모든 수집 데이터는 로컬 SQLite 데이터베이스에 안전하게 보관됩니다.

## ✨ 주요 기능

- ⚡ **초고속 비동기 수집 엔진**: Playwright 기반 Article API 다중 페이지 Fast-Path 수집 및 모바일/웹 응답 캡처 지원 (Selenium 자동 fallback 내장)
- 🏢 **자산 유형 지원**: 아파트(APT) 및 빌라·연립(VL) 매물 수집 지원 (분양권 포함 옵션 지원)
- 🗺️ **2가지 수집 모드**: 단지 ID/URL 직접 지정 수집(`매물 수집`) + 지도 위도/경도 반경 탐색 수집(`지도로 찾기`)
- 🔍 **풍부한 상세 정보 보강**: 중개업소명, 중개사 연락처, 기전세가, 갭투자 금액/비율, 확인일자, 동/층/향 정보
- 📊 **3가지 결과 뷰**: 표준 테이블 뷰 / 동일 매물 묶기(컴팩트) 뷰 / 시각적 카드 뷰
- 📈 **시세 분석 & 가격 이력 추적**: 매 수집 시 일별 가격 스냅샷 자동 기록, 신규 등록 매물 / 가격 상승·하락 / 사라진(거래완료/삭제) 매물 추적
- ⏰ **예약 자동 수집**: 원하는 시간(예: 매일 오전 09:00)에 지정한 단지 그룹 또는 좌표 영역을 백그라운드 자동 수집
- 📑 **엑셀/CSV 맞춤 내보내기**: 원하는 컬럼만 선택하고 순서를 지정할 수 있는 엑셀 템플릿 내보내기

## 💻 설치 및 준비

Python 3.11 이상 환경이 필요합니다.

```powershell
# 1. 가상환경 생성 및 활성화 (권장)
python -m venv .venv
.venv\Scripts\activate

# 2. pip 최신화 및 의존성 패키지 설치
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

# 3. Playwright 브라우저 바이너리 설치
playwright install chromium
```

> ⚠️ **주의 (UI 라이브러리 충돌 방지)**  
> 본 프로젝트는 `PyQt6-Fluent-Widgets`를 사용합니다. `PySide6-Fluent-Widgets`가 함께 설치되면 모듈 충돌(`ModuleNotFoundError: No module named 'PySide6'`)이 발생합니다.  
> 만약 오류가 발생하면 아래 명령으로 재설치하세요:  
> `python -m pip uninstall -y PySide6-Fluent-Widgets`  
> `python -m pip install --force-reinstall "PyQt6-Fluent-Widgets>=1.11.0"`

### 1. 매물 수집 (단지 기반 수집)

단지 번호나 웹 URL을 직접 입력하여 특정 단지들의 매물을 집중적으로 수집하는 화면입니다.

#### ① 단지 추가하기
- **단지 ID 직접 입력**: 상단 입력창에 단지 식별 번호(예: `3833`)를 입력하고 **[추가]**를 누릅니다.
- **URL 일괄 등록 (강력 추천 ⭐)**:
  - **[URL]** 버튼을 클릭하면 `URL 일괄 등록` 대화상자가 열립니다.
  - 네이버 부동산 URL 또는 단지 ID를 한 줄에 하나씩 여러 개 붙여넣습니다.
  - **[URL 분석]**을 누르면 단지명과 자산 유형(아파트/빌라)을 자동으로 조회·검증하며, **[선택 항목 추가]**로 한 번에 목록에 등록할 수 있습니다.
  - 지원 URL 형식:
    - `https://new.land.naver.com/complexes/102378`
    - `https://land.naver.com/complex?complexNo=123456`
    - `https://fin.land.naver.com/articles/2539123450` (개별 매물 URL에서 단지 역조회)
    - `https://m.land.naver.com/article/info/2513105556`

#### ② 수집 조건 및 1차 필터 설정
- **거래 유형**: `매매`, `전세`, `월세` 중 수집을 원하는 유형을 다중 선택합니다.
- **면적 필터**: 최소 평수 ~ 최대 평수를 지정하여 불필요한 평형을 수집 대상에서 제외합니다.
- **가격 필터**: 매매가, 전세가, 월세 보증금/월세 범위를 만원 단위로 필터링합니다.

#### ③ 수집 실행 및 속도 조절
- **수집 시작 (`Ctrl+R`)**: 크롤링 스레드가 시작되며 실시간 진행률과 로그가 출력됩니다.
- **수집 속도 조절**: 슬라이더를 통해 수집 속도를 조절할 수 있습니다 (기본값인 `보통` 권장).
- **중지 (`Ctrl+Shift+R`)**: 진행 중인 수집을 안전하게 중단합니다.

#### ④ 결과 확인 및 뷰 모드 전환
수집된 매물은 3가지 방식으로 열람할 수 있습니다:
- **테이블 뷰**: 모든 매물 컬럼을 정렬 가능한 스프레드시트 형태로 확인
- **묶기(컴팩트) 뷰**: 동일한 동/층/면적의 중복 등록 매물을 그룹화하여 간결하게 표시
- **카드 뷰**: 매물 사진(선택), 주요 정보, 가격 변동 뱃지, 즐겨찾기 버튼이 포함된 시각적 카드 리스트

#### ⑤ 실시간 검색 및 고급 필터링
- **실시간 검색 (`Ctrl+F`)**: 검색창에 단지명, 동, 중개업소, 특징 키워드를 입력하여 즉시 필터링합니다.
- **고급 필터**:
  - **층수 필터**: `저층`, `중층`, `고층` 선택
  - **특수 필터**: `🆕 신규 매물만`, `📉 가격 하락만`, `📊 가격 변동만`
  - **키워드 필터**: 포함할 키워드(예: `급매, 로얄동, 올수리`) 및 제외할 키워드(예: `반지하, 탑층`) 지정
- **컬럼 더보기**: 확인일자, 동, 면적타입, 동일주소 매물 수, 중개업소명, 중개사 연락처 등 상세 컬럼 표시/숨김 전환

#### ⑥ 데이터 저장 및 내보내기
- **엑셀 저장 (`Ctrl+S`)** / **CSV 저장 (`Ctrl+Shift+S`)**
- **엑셀 템플릿 커스텀**: 내보낼 컬럼을 선택하고 위/아래 순서를 자유롭게 조정하여 저장할 수 있습니다.
- **매물 바로가기**: 결과 항목을 **더블 클릭**하면 브라우저에서 해당 네이버 부동산 매물 페이지가 열립니다.

### 2. 지도로 찾기 (좌표 기반 광역 탐색)

단지 번호를 일일이 찾기 어려울 때, 지도 좌표(위도/경도)와 반경을 기준으로 주변의 모든 아파트와 빌라·연립 단지를 자동으로 스캔하여 수집하는 기능입니다.

1. **위도 / 경도 입력**: 탐색할 중심 위치 좌표를 입력합니다 (기본값: 서울 중심).
2. **지도 확대(Zoom)**: `12` ~ `18` 단계 설정 (기본값: `15`).
3. **탐색 범위(링 수)**:
   - `0`: 현재 중심 좌표 위치만 탐색
   - `1 ~ 6`: 중심 좌표를 둘러싼 주변 격자를 순차적으로 스윕 탐색 (반경 확장)
4. **주택 종류 선택**: `아파트(APT)` 및 `빌라·연립(VL)` 체크
5. **세부 탐색 옵션 (고급)**:
   - 칸 간격(px): 스캔 이동 픽셀 간격 (기본 480px)
   - 칸마다 대기 시간(ms): 각 구역별 응답 대기 지연 시간 (기본 600ms)
6. **[탐색 시작]**을 클릭하면 발견된 단지 목록이 실시간으로 표에 채워지며, 매물 수집이 연속으로 진행됩니다.

### 3. 보관함 관리 (내 단지 / 단지 묶음 / 즐겨찾기)

수집한 단지와 매물을 체계적으로 분류하고 관리할 수 있습니다.

- **내 단지 (`DB 관리`)**:
  - 데이터베이스에 저장된 모든 단지 목록을 조회합니다.
  - 단지별 메모 작성/수정, 불필요한 단지 단일/다중 삭제 기능을 제공합니다.
- **단지 묶음 (`그룹 관리`)**:
  - 여러 단지를 관심 주제별(예: `송파구 30평대`, `역세권 재건축`, `투자 후보군`)로 그룹화합니다.
  - 생성된 그룹은 **[예약 수집]**의 대상으로 바로 연동됩니다.
- **즐겨찾기 (`관심 매물`)**:
  - 결과 카드나 표에서 별(⭐) 아이콘을 눌러 등록한 관심 매물 모음입니다.
  - 매물별 개인 메모 편집, 원본 링크 바로가기, 즐겨찾기 해제 기능을 지원합니다.

### 4. 분석 및 모니터링 (대시보드 / 가격 통계 / 수집 기록)

수집된 데이터를 시각화하고 가격 변동을 추적합니다.

- **대시보드**:
  - 현재 수집 매물의 전체 요약 (총 매물 수, 평균가, 평당가 등)
  - 매매/전세/월세 가격 분포 및 평형별 시세 통계
  - 신규 등록 매물 / 가격 상승·하락 매물 / 사라진 매물(거래완료 또는 매물 회수) 분석 차트 제공
- **가격 통계 (시세 추이)**:
  - 단지별, 거래 유형별, 평형별 일별 가격 스냅샷 이력을 선 그래프로 시각화
  - 일자별 최저가 / 최고가 / 평균가 변동 추이 테이블 확인 (월세의 경우 보증금/월세 기준 전환 가능)
- **수집 기록**:
  - 과거 수집 일시, 단지명, 수집 매물 수, 신규/변동 매물 건수 기록 조회 및 관리

### 5. 자동화 (예약 수집 & 트레이 백그라운드)

매일 특정 시간에 PC가 켜져 있으면 자동으로 수집을 수행하도록 스케줄을 구성할 수 있습니다.

1. **실행 모드 선택**:
   - `complex`: 특정 **[단지 묶음]** 그룹을 대상으로 순차 수집
   - `geo_sweep`: 지정된 **[지도 중심 좌표 및 반경]**을 대상으로 탐색 수집
2. **실행 시간 설정**: 수집을 시작할 시각(예: `09:00`) 지정
3. **[예약 실행 켜기]** 체크
4. **트레이 최소화 활용**: 설정에서 `창을 닫을 때 트레이로 최소화`를 켜두면, 창을 닫아도 백그라운드(시스템 트레이)에서 동작하며 정해진 시간에 자동 수집을 수행합니다.

### 7. 데이터 백업 및 복원

수집된 단지 정보, 매물 목록, 가격 스냅샷 이력은 로컬 DB에 안전하게 보관되며 언제든 백업/복원할 수 있습니다.

- **DB 백업**: 상단 메뉴 `파일` → `DB 백업` 선택 ➔ 원하는 위치에 `.db` 파일로 저장
- **DB 복원**: 상단 메뉴 `파일` → `DB 복원` 선택 ➔ 백업 파일(`.db`) 선택
  - *안전 장치*: 진행 중인 크롤링 스레드와 타이머를 자동으로 안전 종료하고, 유지보수 모드로 진입하여 데이터 무결성을 보호합니다.

## 💡 실전 활용 팁

1. **단지 ID를 찾는 가장 쉬운 방법**:
   - PC 웹 브라우저에서 네이버 부동산 접속 ➔ 원하는 아파트 단지 클릭
   - 브라우저 주소창 URL 확인: `https://new.land.naver.com/complexes/102378` ➔ 끝의 숫자 `102378`이 단지 ID입니다.
   - 단지 번호를 찾기 귀찮다면 URL 전체를 복사해서 프로그램의 **[URL]** 일괄 등록 창에 그냥 붙여넣으세요!
2. **안정적인 대량 수집 요령**:
   - 수십 개 이상의 대형 단지를 한 번에 수집할 때는 `수집 속도`를 `보통` 또는 `안전`으로 설정하세요.
   - 설정 → 고급에서 `목록 페이지 사이 대기(ms)`를 `200~300ms` 정도로 늘려주면 429(Too Many Requests) 차단을 효과적으로 예방할 수 있습니다.
3. **갭투자 및 급매물 모니터링**:
   - 관심 단지들을 `단지 묶음`으로 등록해 두고 매일 아침 `예약 수집`을 실행합니다.
   - 수집 후 `고급 필터`에서 `🆕 신규 매물만` 또는 `📉 가격 하락만`을 체크하면 밤사이 새로 나온 매물이나 호가를 낮춘 급매물을 즉시 포착할 수 있습니다.
   - 결과 표의 `갭금액` 및 `갭비율(%)` 컬럼을 확인하여 전세가율이 높은 매물을 손쉽게 선별할 수 있습니다.

## 📦 단독 실행 파일 빌드 (PyInstaller)

Python이 설치되지 않은 환경에서도 배포 및 실행이 가능한 단독 패키지를 빌드할 수 있습니다 (`naverland-scrapper.spec` 사용).

```powershell
# 기본 onedir 빌드 (dist/naverland/ 생성)
python -m PyInstaller --clean --noconfirm naverland-scrapper.spec
```

#### 빌드 커스터마이징 환경 변수
| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `NAVERLAND_ONEFILE=1` | 0 | 단일 실행 파일(`.exe`)로 패키징 |
| `NAVERLAND_BUNDLE_CHROMIUM=0` | 1 | 빌드에서 Chromium 번들을 제외하여 배포 용량 대폭 절감 |
| `NAVERLAND_INCLUDE_SELENIUM=0` | 1 | Selenium 의존성을 제외하고 Playwright 전용 경량 빌드 생성 |
| `NAVERLAND_CONSOLE=1` | 0 | 디버깅용 콘솔 창을 실행 시 함께 표시 |

*경량 슬림 빌드 예시:*
```powershell
$env:NAVERLAND_BUNDLE_CHROMIUM="0"
$env:NAVERLAND_INCLUDE_SELENIUM="0"
python -m PyInstaller --clean --noconfirm naverland-scrapper.spec
```
